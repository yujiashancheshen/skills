# Tech Deck（技术演示文稿生成）

把技术内容（文章、PPT 要点、架构、观点、数据）变成业内顶尖水准的 HTML 演示文稿。核心思路：**不让你硬写、硬选**，而是由模型先诊断宣讲对象与目的 → 主推一套叙事讲法 → 推荐模板 → 逐页确认大纲（含每页核心信息）→ 生成单文件 HTML → 自动校验。

零依赖、单文件、浏览器直接打开。

## 怎么使用

使用 `tech-deck` 技能，直接把要做演示的内容丢给我即可：

`帮我把这篇内容做成演示：……`

我会先问清宣讲对象和目的 → 主推一套叙事讲法 → 推荐主推+备选模板 → 列大纲让你逐页确认（含每页核心信息）→ 生成 → 自检后交付。

## 工作流程

本 skill 把一段技术内容变成一份演示文稿，分 7 步：

0. **诊断问答** — 判断宣讲对象、目的、长度、是否需要联网补料、是否要演讲稿；能推断的自己推断，只问关键项
1. **叙事框架** — 根据宣讲对象主推 1 套讲法 + 理由（金字塔 / SCQA / 问题-方案-收益 / What-Why-How / 故事线）
2. **AI 推荐模板** — 主推 1 套 + 备选 1 套并说明理由，只生成主推预览（不全量预览）
3. **列大纲** — 逐页列出标题、内容、推荐版式，并标注每页一句话核心信息（take-away），你可逐页调整
4. **生成** — 读取模板规格 + 版式目录 + 布局铁律 + 内容铁律，构建完整 HTML
5. **校验** — 截图检查无溢出、导航正常
6. **交付** — 打开文件，说明定制方法
7. **演讲稿（可选）** — 需要时,确认风格/时长后生成逐页口语讲解稿,与演示同目录

## 叙事结构与内容铁律

排版之前先定「怎么讲」。我会根据宣讲对象和目的，从 5 套经典框架里主推 1 套并说明理由（完整说明见 `templates/_叙事结构.md`）：

| 宣讲对象 | 首选框架 |
|---|---|
| 公司高管 / 决策层 | 金字塔原理（结论先行）/ SCQA |
| 同行工程师 / 技术评审 | What-Why-How |
| 客户 / 投资人 | 问题-方案-收益 / 故事线 |
| 团队内部 | What-Why-How / 故事线 |
| 大会主题演讲 | 故事线 / 英雄之旅 |

每页文案还强制遵守内容铁律：**每页一个 take-away、先具体后解释、用证据代替形容词、标题是观点不是标签、禁用空洞套话、不编造数据**。

## 约 23 种版式（逐页可选）

版式与模板正交：模板管「整体长什么样」，版式管「这一页内容怎么排」。同一版式在不同模板下呈现各自气质。完整目录见 `templates/_版式目录.md`，按内容类型分 8 类：

开场过渡 · 罗列信息 · 对比 · 数据 · 结构关系 · 叙事 · 专项 · 收尾

列大纲时，我会为每页推荐合适的版式，你可逐页替换（如「第 3 页换成数据仪表」）。

每种版式长什么样，可打开 `templates/_版式目录.html` 查看——用暗夜微光风把全部版式各做一屏，方便直观挑选。

## 布局质量铁律

无论哪套模板，强制遵守（见 `templates/_布局铁律.md`）：

1. **每页一个视觉焦点** — 不平铺，用大小/留白/颜色制造主次
2. **大字号** — 标题 `clamp(2.5rem, 7vw, 6rem)` 起，正文 ≥ `0.95rem`
3. **重点高亮** — 关键词加色/加重，绝不全是灰字
4. **留白优先** — 内容少而精，宁可拆页
5. **视口适配** — 每页恰好一屏，绝不内部滚动

## 操作

生成的 HTML 用方向键 / 滚轮 / 触摸滑动翻页，右侧导航点可跳转，顶部进度条显示进度。
