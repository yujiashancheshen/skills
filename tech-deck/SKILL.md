# Tech Deck — 技术演示文稿生成

把技术内容变成业内顶尖水准的 HTML 演示文稿。零依赖、单文件、浏览器直接打开。

## 核心原则

1. **AI 推荐先行**：不让用户硬选。AI 分析内容气质，主推 1 套模板 + 备选 1 套，说明理由。
2. **大纲确认**：生成前必须逐页确认内容+版式，用户可逐页调整。
3. **模板 = 完整视觉语言**：色彩 + 空间 + 字体 + 偏好版式 + 动画 + 翻页，不是单纯配色。
4. **布局质量铁律**：必须像业内顶尖 PPT —— 大字号、每页一焦点、重点高亮、留白优先。见 `styles/_layout-rules.md`。
5. **逐页选版式**：版式与模板正交，每页可独立选。见 `styles/_layouts.md`（约 23 种）。
6. **自动校验**：生成后用 Playwright 截图验证 **1920×1080** 无溢出（默认只测此分辨率提速，多分辨率基本不常用）。
7. **零依赖**：单 HTML 文件，内联 CSS+JS，字体仅 Google Fonts。

## 6 套模板（完整视觉语言）

每套都是经过调校、对标业内顶尖产品的完整体系。规格见 `templates/<名>.md`，效果样例见同名 `templates/<名>.html`。

| 模板 | 对标 | 气质 | 适合 |
|------|------|------|------|
| 暗夜微光风 | Linear/Vercel | 暗色高级、科技发布会 | AI、基础设施、技术战略 |
| 清晰商务风 | Stripe | 金融级信任、明亮专业 | 产品发布、商业汇报、路演 |
| 杂志墨刊风 | Kinfolk杂志 | 文艺有格调、深度叙事 | 技术演讲、思考型分享 |
| 极简黑白风 | Apple Keynote | 极致对比、自信有力 | 发布、立场宣言 |
| 暖意画布风 | Notion/Things | 柔性极简、温暖亲和 | 产品概览、团队分享 |
| 极光未来风 | AI 产品 | 未来感、惊艳 | AI 产品、前沿技术 |

## 工作流程

```
1. 接收内容 → 分析主题/受众/长度/气质
2. AI 推荐  → 主推 1 套 + 备选 1 套，说明理由；只生成主推预览（要看备选再生成）
3. 列大纲   → 逐页列出标题、内容、推荐版式；用户可逐页调整
4. 生成     → 读取模板规格 + 版式目录 + 布局铁律，构建完整 HTML
5. 校验     → Playwright 截图检查多分辨率无溢出
6. 交付     → 打开文件，删除预览，说明定制方法
```

### 步骤 1：接收内容

了解：内容来源（文章/笔记/大纲/仅主题）、用途、长度偏好、受众。
用户已给内容则直接分析其**气质**（理性/感性、数据型/叙事型、对内/对外、前沿/稳重）。

### 步骤 2：AI 推荐模板（不全量预览）

**关键改进：不再 6 套全生成预览让用户挑。**

基于内容气质分析，AI 主动推荐：
- **主推 1 套** + 一句话理由（为什么这套最契合）
- **备选 1 套** + 一句话理由（什么情况下选它）

只为**主推**生成一个 4 页预览 HTML 放 `preview/`，打开给用户看。
用户想看备选，再生成备选预览。用户认可主推，直接进下一步。

推荐逻辑参考：
- AI/技术战略/暗色高级 → 暗夜微光风
- 对外商业/产品发布/明亮可信 → 清晰商务风
- 深度演讲/思考叙事 → 杂志墨刊风
- 立场宣言/强冲击 → 极简黑白风
- 团队内部/温暖轻松 → 暖意画布风
- AI 产品/惊艳前沿 → 极光未来风

### 步骤 3：列大纲（逐页版式推荐，必须确认）

展示完整大纲，**每页标注推荐版式**（版式标识见 `styles/_layouts.md`）：

```
幻灯片大纲（共 X 页，模板：XXX）：

第 1 页 [hero 封面]
  标题：XXX  副标题：XXX

第 2 页 [stat-hero 数据英雄]
  核心数字：XXX  说明：XXX

第 3 页 [cards 卡片网格]
  标题：XXX
  • 卡1 …  • 卡2 …  • 卡3 …

...（逐页）
```

用户可逐页调整："第 3 页换成 dash 数据仪表"、"加一页 quote"、"删掉第 5 页"。
**确认后才生成。绝不在未确认大纲时直接生成。**

### 步骤 4：生成

读取三份规格：
1. 选定模板 `templates/<名>.md`（色彩/字体/空间/出彩点/动画），可参考同名 `.html` 样例
2. 版式目录 `templates/_版式目录.md`（每页对应版式的结构）
3. 布局铁律 `templates/_布局铁律.md`（大字号/焦点/高亮/留白）

构建完整 HTML，含：语义化 slide、视口安全 CSS、键盘/触摸/滚轮导航、IntersectionObserver 错落淡入、`prefers-reduced-motion`、进度条+页码+导航点。

输出到用户当前工作目录，文件名 `[主题]-[模板].html`。

### 步骤 5：自动校验

**默认只校验 1920×1080**（演示主场景）。截图检查：无溢出滚动条、导航可用、文字不截断重叠。发现问题自动修复重校验。

多分辨率（1280×720 / 768×1024 / 375×667 / 667×375）基本不常用,**默认忽略以提速**;仅当用户明确要求适配移动端/多端时才补测其余分辨率。

Playwright 不可用时做结构检查：每个 `.slide` 有 `100vh/100dvh/overflow:hidden`、字号用 `clamp()`、无固定高度容器。

### 步骤 6：交付

删除 `preview/` 临时文件 → 打开 HTML（macOS `open`）→ 告知：文件路径、模板名、页数、改主题色的 CSS 变量、操作方式。

## 参考文件索引

- `templates/_版式目录.md` — 约 23 种版式目录（逐页选）
- `templates/_布局铁律.md` — 布局质量铁律（强制）
- `templates/<名>.md` 6 个 — 模板完整规格；同名 `.html` 为效果样例

## 反模式（禁止）

- 把模板做成"只换配色"（必须是完整视觉语言）
- 字太小（正文 < 0.95rem）、内容平铺无焦点、全灰字无高亮
- 6 套全量预览才让用户选（应 AI 推荐主推+备选）
- 未确认大纲就生成
- 超长文字墙、需滚动的代码块、固定高度容器
- 紫白渐变通用模板、Inter/Arial 当主视觉（除非模板指定）
