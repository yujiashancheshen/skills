# Aurora 模板

> 完整视觉语言。对标各家 AI 产品。未来感、惊艳。

## 气质

前沿、AI、惊艳。适合 AI 产品、前沿技术、需要"哇"效果的发布。

## 色彩系统

```css
:root {
    --bg: #0B1437;          /* 深海军蓝 */
    --bg-elev: #111B42;     /* 抬升层 */
    --bg-glass: rgba(255,255,255,0.06);  /* 玻璃卡片 */
    --fg: #F0F4FF;          /* 主文字 */
    --fg-dim: #A6B0D4;      /* 次文字 */
    --fg-faint: #6B7399;    /* 弱文字 */
    --line: rgba(255,255,255,0.12);
    --cyan: #22D3EE;        /* 极光青 */
    --violet: #A78BFA;      /* 极光紫 */
    --pink: #F0ABFC;        /* 极光粉 */
    --aurora: linear-gradient(120deg, #22D3EE, #A78BFA 50%, #F0ABFC);
}
```

## 字体

- 标题 `Space Grotesk`（500-700），正文同族 400-500
- 中文 `Noto Sans SC`

## 空间语言

- 深蓝底叠极光渐变光晕
- 玻璃拟态卡片（磨砂模糊 `backdrop-filter: blur(20px)`）
- 霓虹边框，发光强调

## 出彩点（签名元素）

1. **极光渐变光晕**：青→紫→粉的流动模糊光团
2. **玻璃拟态卡片**：半透明 + 磨砂模糊 + 细边框
3. **霓虹边框**：卡片/按钮发光边
4. **渐变文字**：标题关键词用 `--aurora` 渐变
5. **流动背景**：渐变光晕缓慢移动

## 偏好版式

最契合：`hero` `stat-hero` `cards` `dash` `statement` `flow` `hub`
特色：卡片全用玻璃拟态；强调元素发光

## 动画性格

流动。淡入 + 渐变光晕缓慢漂移。玻璃卡 hover 发光增强。比 Linear 更"活"。

## 翻页方式

平滑滚动吸附 + 进度条（极光渐变）。
