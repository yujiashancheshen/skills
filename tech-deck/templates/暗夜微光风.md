# Linear Dusk 模板

> 完整视觉语言 = 色彩 + 空间 + 字体 + 偏好版式 + 动画 + 翻页。对标 Linear / Vercel。

## 气质

冷静、克制、科技公司发布会。暗色高级感。适合 AI、基础设施、开发工具、技术战略类主题。

## 色彩系统

```css
:root {
    --bg: #08090A;          /* 近黑主底 */
    --bg-elev: #0E0E11;     /* 抬升层 */
    --bg-card: #121317;     /* 卡片底 */
    --fg: #F7F8F8;          /* 主文字 */
    --fg-dim: #9CA0A8;      /* 次文字 */
    --fg-faint: #62666D;    /* 弱文字 */
    --line: rgba(255,255,255,0.08);
    --line-bright: rgba(255,255,255,0.14);
    --indigo: #5E6AD2;      /* 主强调 靛紫 */
    --blue: #4EA8DE;        /* 副强调 电蓝 */
    --glow: rgba(94,106,210,0.35);
}
```

## 字体

- 统一 `Inter` + `Noto Sans SC`
- 标题超紧字距 `-0.03em`，正文 `-0.011em`
- 标题 800-900，正文 400-500

## 空间语言

- 大留白，`--pad: clamp(2.5rem, 6vw, 7rem)`
- 内容垂直居中，左对齐为主
- 卡片圆角 16px，细边框 1px
- 网格背景 64px，径向遮罩淡出边缘

## 出彩点（签名元素）

1. **渐变文字**：标题关键词用 `linear-gradient(120deg, fg, indigo, blue)` 裁切
2. **角落辉光**：模糊 120px 的靛紫/电蓝光晕，右上+左下
3. **星点网格背景**：64px 网格 + 径向遮罩，营造空间纵深
4. **卡片顶部光线**：hover 时顶部出现渐变细线 + 上浮 3px
5. **超大数字**：数据英雄页数字达 16rem，渐变文字

## 偏好版式

最契合：`hero` `stat-hero` `cards` `dash` `flow` `statement` `split`
特色处理：卡片用 feature 类做高亮焦点卡（靛紫渐变底）

## 动画性格

冷静溶解。错落淡入（translateY 20px），延迟 d1-d6。卡片 hover 上浮。不做弹跳。

## 翻页方式

平滑滚动吸附 + 进度条（靛紫→电蓝渐变）。
