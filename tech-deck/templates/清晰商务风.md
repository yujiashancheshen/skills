# Stripe Clarity 模板

> 完整视觉语言。对标 Stripe。金融级信任感。

## 气质

专业、可信、明亮。适合产品发布、商业汇报、对外路演、需要"靠谱感"的场合。

## 色彩系统

```css
:root {
    --bg: #FFFFFF;          /* 纯白主底 */
    --bg-soft: #F6F9FC;     /* 浅灰蓝 */
    --bg-dark: #0A2540;     /* 深岩蓝(反转页) */
    --fg: #0A2540;          /* 深岩蓝文字 */
    --fg-dim: #425466;      /* 次文字 */
    --fg-faint: #8898AA;    /* 弱文字 */
    --line: rgba(10,37,64,0.1);
    --blurple: #635BFF;     /* 主强调 */
    --cyan: #00D4FF;        /* 副强调 */
    --green: #00D924;       /* 成功色 */
    --grad: linear-gradient(108deg, #635BFF, #00D4FF 60%, #00D924);
}
```

## 字体

- `Manrope` + `Noto Sans SC`（接近 Stripe 的 Söhne 几何感）
- 标题 700-800，正文 400-500，字距 `-0.02em`

## 空间语言

- 白底为主，关键页用 `--bg-dark` 深岩蓝反转
- 卡片柔和分层投影 `0 15px 35px rgba(10,37,64,0.08)`
- 圆角 12px，留白克制有序

## 出彩点（签名元素）

1. **多色渐变斜切带**：blurple→cyan→green 的 `--grad`，斜切角度装饰条
2. **柔和投影分层**：卡片浮于背景，层次分明
3. **数据可视化精致**：条形/环形图用渐变填充
4. **反转强调页**：深岩蓝底白字做章节/金句，强烈对比
5. **细腻图标**：线性图标配 blurple

## 偏好版式

最契合：`hero` `cards` `dash` `bars` `flow` `split` `table` `cta`
特色：用斜切渐变带分隔区块；数据页用渐变条形图

## 动画性格

专业平稳。200-300ms 过渡。淡入 + 轻微上移。渐变带可缓慢流动。

## 翻页方式

平滑滚动吸附 + 进度条（多色渐变）。
