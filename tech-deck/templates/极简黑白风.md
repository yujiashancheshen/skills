# Mono Bold 模板

> 完整视觉语言。对标 Apple Keynote。极致对比。

## 气质

自信、有力、keynote 名场面。适合发布、立场宣言、需要冲击力的场合。

## 色彩系统

```css
:root {
    /* 默认黑底白字，可整体反转 */
    --bg: #000000;
    --fg: #FFFFFF;
    --fg-dim: rgba(255,255,255,0.55);
    --fg-faint: rgba(255,255,255,0.3);
    --line: rgba(255,255,255,0.15);
    --signal: #FF3B30;      /* 单一信号色,可调 */
}
/* 反转版：--bg:#FFF; --fg:#000; --signal 不变 */
```

## 字体

- 单一无衬线超粗：`Archivo`（900）做标题，`Archivo`（400-600）做正文
- 中文 `Noto Sans SC`（900/700）
- 标题字距收紧 `-0.04em`

## 空间语言

- 极简。一页一焦点。
- 超大字撑满屏，大量留白
- 强烈黑白对比，信号色只点睛（绝不滥用）

## 出彩点（签名元素）

1. **超大字撑屏**：标题/数字占据视觉绝对主导
2. **一页一焦点**：每页只有一个最大的东西
3. **信号色点睛**：红色只用在 1-2 个关键词，其余纯黑白
4. **整页反转**：黑白页交替制造节奏
5. **极简留白**：内容极少，气场极大

## 偏好版式

最契合：`statement` `stat-hero` `section` `quote` `hero` `bullets`
特色：避免密集卡片网格；数据用单个超大数字

## 动画性格

果断。快速淡入 + 大尺度（200ms）。信号色可做强调闪现。不拖泥带水。

## 翻页方式

平滑滚动吸附 + 极细进度条（信号色）。
