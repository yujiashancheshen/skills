# 布局质量铁律（所有模板强制遵守）

解决"字小、不突出重点、像网页不像 PPT"的根本规则。无论哪套模板,生成时都必须遵守。

## 1. 每页一个视觉焦点

- 不平铺。用大小 / 留白 / 颜色制造主次。
- 一页只讲一件事。一页只有一个最大的东西。
- 数据页让核心数字成为焦点(超大);观点页让那句话成为焦点。

## 2. 大字号

| 元素 | 最小字号 |
|------|---------|
| 封面大标题 | `clamp(2.8rem, 7vw, 6rem)` |
| 页面标题 H2 | `clamp(1.6rem, 3.8vw, 3rem)` |
| 卡片小标题 H3 | `clamp(1.05rem, 1.8vw, 1.45rem)` |
| 正文 | `clamp(0.95rem, 1.35vw, 1.2rem)`，**绝不低于 0.95rem** |
| 超大数字 | `clamp(5rem, 18vw, 16rem)` |

- 六卡等密集网格,正文用 `dense` 修饰再放大一档(≥ 1.05rem)。

## 3. 重点高亮

- 关键词必须突出:加色(强调色)、加重(600+)、或加色块底。
- **绝不让一页内容全是同一种灰色**。
- 每段话至少有 1-2 个高亮词锚定视线。

## 4. 留白优先

- 内容少而精。宁可拆成两页,也不塞满一页。
- 内容区四周留足边距(`--pad` 不小于 `clamp(2.5rem, 6vw, 7rem)`)。
- 元素间距统一节奏,不要忽大忽小。

## 5. 专业排版细节

- 标题字距收紧(`letter-spacing: -0.02em ~ -0.03em`),正文略收(`-0.01em`)。
- 数字用 `font-variant-numeric: tabular-nums` 对齐。
- 行高:标题 1.05-1.1,正文 1.5-1.65。
- 网格对齐,统一圆角,统一边框粗细。

## 6. 视口适配(硬性)

- 每个 `.slide`:`height: 100vh; height: 100dvh; overflow: hidden`。
- 所有字号/间距用 `clamp()`。
- 短屏断点 740 / 600px 降级字号。
- 放不下就拆页,**绝不** `overflow: auto`。

## 7. 动画(基础)

- 入场:错落淡入(`opacity` + `translateY(20px)`),延迟 d1-d6 阶梯。
- 翻页:平滑滚动吸附。
- 微交互:卡片 hover 轻微上浮可选。
- `prefers-reduced-motion` 必须降级。
- 不做花哨动画,克制为主。
