# Editorial Ink 模板

> 完整视觉语言。对标 Kinfolk / Monocle 杂志。

## 气质

文艺、有格调、深度内容。适合技术演讲、思考型分享、长内容叙事。

## 色彩系统

```css
:root {
    --bg: #F4F1EA;          /* 暖奶油 */
    --bg-card: #FBF9F4;     /* 浅纸 */
    --fg: #1A1815;          /* 墨黑 */
    --fg-dim: #5C5138;      /* 深橄榄次文字 */
    --fg-faint: #9A8F7A;    /* 弱文字 */
    --line: rgba(26,24,21,0.12);
    --ochre: #B5562E;       /* 赭石主强调 */
    --olive: #5C5138;       /* 深橄榄副 */
}
```

## 字体（双衬线）

- 大标题 `Fraunces`（700-900，可斜体）
- 正文 `Newsreader`（400-500，衬线，易读）
- 中文 `Noto Sans SC`

## 空间语言

- 杂志栏式排版，栏线分隔
- 留白节奏讲究，页眉页脚装饰线
- 首字下沉（drop cap）用于长段落
- 大图文混排

## 出彩点（签名元素）

1. **首字下沉**：段落首字放大，Fraunces 衬线
2. **栏线分隔**：细竖线分栏，杂志感
3. **斜体强调**：关键词 `em` 斜体 + 赭石色
4. **页眉页脚装饰**：顶部页码/章节名，底部细线
5. **大图文混排**：图片占半屏，文字栏式环绕

## 偏好版式

最契合：`statement` `quote` `split` `image` `bullets` `section` `problem-solution`
特色：编号用罗马数字/汉字数字；引用页用大号衬线

## 动画性格

极克制。仅淡入（500-700ms）。不做弹跳/旋转。翻页如翻杂志页。

## 翻页方式

平滑滚动吸附 + 细进度条（赭石色）。
