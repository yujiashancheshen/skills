# Warm Canvas 模板

> 完整视觉语言。对标 Notion / Things。柔性极简。

## 气质

温暖、舒适、亲和。适合产品概览、团队分享、内部文化、轻松汇报。

## 色彩系统

```css
:root {
    --bg: #FAF9F6;          /* 暖砂底 */
    --bg-card: #FFFFFF;     /* 纸白卡片 */
    --fg: #37352F;          /* 暖灰文字 */
    --fg-dim: #787066;      /* 次文字 */
    --fg-faint: #A8A096;    /* 弱文字 */
    --line: rgba(55,53,47,0.1);
    --terracotta: #D2691E;  /* 陶土主强调 */
    --sage: #87A96B;        /* 鼠尾草副 */
    --shadow: 0 4px 20px rgba(55,53,47,0.06);
}
```

## 字体

- `Plus Jakarta Sans` + `Noto Sans SC`，圆润友好
- 标题 700-800，正文 400-500

## 空间语言

- 柔和圆角（卡片 16-20px）
- 纸感卡片，轻柔投影 `--shadow`
- 克制配色，大量舒适留白
- 元素呼吸感强

## 出彩点（签名元素）

1. **纸感卡片**：白卡浮于暖砂底，柔和投影
2. **柔和圆角**：所有元素大圆角，无锐利边
3. **陶土/鼠尾草点缀**：克制的暖色强调
4. **彩色小标签**：圆角药丸标签分类
5. **亲和图标**：圆润线性图标配暖色

## 偏好版式

最契合：`cards` `bullets` `checklist` `icon-grid` `split` `summary` `cta`
特色：卡片配彩色图标方块；标签用药丸圆角

## 动画性格

柔和。轻弹入（cubic-bezier 带回弹）。卡片 hover 微浮。温和不跳脱。

## 翻页方式

平滑滚动吸附 + 圆角进度条（陶土色）。
