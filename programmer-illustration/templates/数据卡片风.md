# 数据卡片风 模板

> 样图（仅供参考）：见同目录 `数据卡片风.png`

## 风格特征（不要改，这是这套风格的灵魂）
> ⚠️ 干净 ≠ 扁平。卡片要**明显抬起、有厚度和柔和投影**，图标是**精致的立体插画图标**，背景用浅色柔和渐变制造纵深——不是一张压在平面上的表格。
- 卡片**有体积**：圆角卡片明显抬起、带柔和投影，像悬浮的面板
- **有一个视觉主体(hero)**：一个立体的隐喻装置（如时钟/沙漏/仪表盘）锚定主题，不是纯数字堆
- **大号数字**当焦点，配**立体插画图标**，一眼抓住重点
- 图表（柱/环/折线/进度条）**保持干净精确**，可有轻微立体描边，但**绝不做廉价 3D 饼图**
- 涨用绿、跌用红，语义色固定
- 留白充足、严格对齐，专业但有纵深质感

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 背景 | `#F7F8FA`（浅灰） | 整图底色 |
| 卡片 | `#FFFFFF` + 细描边 `#E6E9EF` | 每张卡片 |
| 主蓝 | `#3B6EF5` | 主数据、主图表、主强调 |
| 涨/正向绿 | `#28B485` | 增长、正向指标 |
| 跌/负向红 | `#E5533C` | 下降、负向指标、警示 |
| 大数字字 | `#1F2430`（近黑） | 卡片里的大号数字 |
| 标签字 | `#6B7280`（中灰） | 数字下的说明文字 |
> 语义色固定：绿=涨/好、红=跌/差、蓝=中性主色。不要乱用颜色。

### 字体
- 大数字：无衬线**粗体**，字号要大、要有冲击力（可用等宽数字对齐）
- 标题/标签：无衬线常规/中体，清晰，层级分明

### 匠人级要求（每次都要带）
成图要像**一线产品的数据周报 / 麦肯锡级信息图**：网格对齐到像素、数字排版讲究、图表精确克制，绝不是随手拼的廉价图表。

### 反 AI 味护栏（负向，必须避开）
- ✗ 乱画的假图表（坐标轴/比例对不上、数据虚假）
- ✗ 卡片不对齐、大小乱、间距忽宽忽窄
- ✗ 花哨渐变、3D 饼图、廉价阴影
- ✗ 数字乱码、小数点错乱、文字压边

## 需要向用户收集的槽位
| 槽位 | 含义 | 必填 | 追问示例 |
|---|---|---|---|
| `{{主标题}}` | 顶部主题 | 是 | "这份数据图的标题？" |
| `{{副标题}}` | 时间范围/来源等 | 否 | "要标注时间范围或数据来源吗？" |
| `{{核心数字卡片[]}}` | 几个 KPI：数字+标签(+涨跌) | 是 | "要突出哪几个核心数字？各自的标签和涨跌？" |
| `{{图表项}}` | 需要一两个图表表现的对比/趋势 | 否 | "有需要画成柱状/环形/折线的对比或趋势吗？" |

## 提示词骨架（把槽位替换后整体喂给出图模型）

```
画一张数据卡片信息图（clean data dashboard infographic, KPI card grid, big numbers, minimal precise charts）。

配色严格使用这套色板，不要自由发挥：背景浅灰 #F7F8FA，卡片纯白 #FFFFFF + 细描边 #E6E9EF；主色蓝 #3B6EF5；语义色固定——增长/正向用绿 #28B485，下降/负向用红 #E5533C；大号数字用近黑 #1F2430，说明标签用中灰 #6B7280。不要乱用颜色。
字体：大数字用无衬线粗体、字号大有冲击力（数字对齐）；标题/标签用无衬线常规/中体，层级分明。

【主标题】顶部左对齐：{{主标题}}
【副标题】标题下方小灰字（时间/来源）：{{副标题}}

主体是一个对齐严格的卡片网格，每张卡片一个核心指标：
{{核心数字卡片1（大数字+标签+涨跌箭头）}}、{{核心数字卡片2}}、{{核心数字卡片3}}……
如有对比/趋势，用简洁精确的图表表现：{{图表项}}（柱状/环形/折线/进度条，配色用主蓝+语义绿红）。

构图比例 16:9，网格像素级对齐，留白充足，信息清晰。成图要像一线产品的数据周报/麦肯锡级信息图，绝不能出现假图表、3D饼图、花哨渐变、卡片错位或数字乱码。所有数字与文字精确清晰、不压边、不重叠。
```
