# 等距立体风 模板

> 样图（仅供参考）：见同目录 `等距立体风.png`

## 风格特征（不要改，这是这套风格的灵魂）
- 等距视角（isometric，约 30° 斜俯视），所有元素**透视统一**
- 模块=立体方块/平台/服务器/楼层，体现"分层、堆叠、连接"
- 柔和长投影，营造空间感但不厚重
- 干净的连接线/管道在立体空间里穿行
- 清爽配色 + 少量暖色点缀，活泼但专业
- 文字以浮在元素旁的小标签为主

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 背景 | `#F4F6FB`（极浅冷灰） | 整图底色 |
| 主蓝 | `#5B8DEF` | 主要立体块 |
| 青 | `#4FC3C3` | 次要立体块 |
| 紫 | `#9B8CFF` | 第三类立体块 |
| 暖橙点缀 | `#FF9E64` | 关键块/高亮，占比少 |
| 投影 | `#D6DCEA`（柔和冷灰） | 立体长投影 |
| 标题字 | `#2A2F45`（深蓝灰） | 主标题 |
| 标签字 | `#5A6275`（中灰） | 元素旁小标签 |
> 蓝-青-紫同色系打底，暖橙只点关键，占比 <10%；投影统一方向、柔和。

### 字体
- 标题：无衬线中/粗体，干净现代
- 标签：无衬线常规，小而清晰，统一字号

### 匠人级要求（每次都要带）
成图要像**专业 SaaS 官网首页那种精致的 isometric 主插画**：透视绝对统一、块面干净、投影柔和一致，绝不是透视错乱的廉价矢量。

### 反 AI 味护栏（负向，必须避开）
- ✗ 透视不一致、块体歪斜、近大远小错乱
- ✗ 糊面、脏渐变、过重阴影
- ✗ 元素堆得太满、连接线乱缠
- ✗ 标签文字压块、压边、乱码

## 需要向用户收集的槽位
| 槽位 | 含义 | 必填 | 追问示例 |
|---|---|---|---|
| `{{主标题}}` | 顶部主题 | 是 | "总标题是什么？" |
| `{{副标题}}` | 一句话说明 | 否 | "要副标题吗？" |
| `{{分层/模块[]}}` | 各立体块代表什么 | 是 | "系统分哪几层/几块？从下到上是什么？" |
| `{{连接关系}}` | 模块之间怎么连 | 是 | "它们之间怎么连/数据怎么流？" |
| `{{高亮模块}}` | 想用暖橙突出的那块 | 否 | "哪一块最关键、要高亮？" |

## 提示词骨架（把槽位替换后整体喂给出图模型）

```
画一张等距 3D 风格的技术架构插画（isometric illustration, 30° view, clean modern vector, consistent perspective, soft long shadows）。

配色严格使用这套色板，不要自由发挥：背景极浅冷灰 #F4F6FB；立体块用主蓝 #5B8DEF / 青 #4FC3C3 / 紫 #9B8CFF 同色系，关键块用暖橙 #FF9E64 高亮（占比 <10%）；投影统一柔和的冷灰 #D6DCEA、方向一致。标题字深蓝灰 #2A2F45，标签字中灰 #5A6275。
字体：标题无衬线中/粗体，标签无衬线常规小字、字号统一。

【主标题】顶部：{{主标题}}
【副标题】标题下方小字：{{副标题}}

用等距立体块/平台表现 {{分层/模块1}}、{{分层/模块2}}、{{分层/模块3}}……（按分层从下到上或从左到右堆叠摆放）。
模块之间按【{{连接关系}}】用干净的等距连接线/管道连接，体现数据/调用流向。
把【{{高亮模块}}】用暖橙突出。每个模块旁浮一个小标签写明名称。

构图比例 16:9，所有元素透视严格统一，块面干净，投影柔和一致，留白舒适。成图要像专业 SaaS 官网的精致 isometric 主插画，绝不能透视错乱、糊面、脏渐变或元素堆满。所有文字清晰可读、不压块、不压边、无乱码。
```

## 已填示例
- 主标题：云原生部署架构
- 分层（下→上）：基础设施层(K8s 节点) → 服务网格 → 微服务集群 → API 网关 → 客户端
- 连接关系：自下而上的调用 + 服务网格横向连接
- 高亮模块：API 网关
