# 暗色科技风 模板

> 样图（仅供参考）：见同目录 `暗色科技风.png`

## 风格特征（不要改，这是这套风格的灵魂）
- 深空蓝黑背景，低对比网格底纹，像高级仪表盘/HUD
- 玻璃拟态卡片（半透明、细边、微弱内发光）
- 霓虹**点到为止**——青/蓝/紫做强调线与高光，绝不满屏彩虹
- 数据流线、连接线、节点，体现"系统在运转"
- 大号细体英文/数字 + 简洁中文标签
- 冷峻、克制、高级，不是赛博朋克霓虹轰炸

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 主背景 | `#0B1220`（深空蓝黑） | 整图底色 |
| 卡片背景 | `#111A2E`（半透明叠加） | 玻璃拟态面板 |
| 网格/分隔线 | `#1E2A44`（低对比） | 底纹、卡片描边 |
| 主霓虹青 | `#34E0E0` | 关键高光、活跃节点、数据流 |
| 主霓虹蓝 | `#4F8CFF` | 连接线、次强调 |
| 辅紫 | `#8B7BFF` | 极少量点缀/渐变收尾 |
| 标题字 | `#F5F8FF`（近白） | 主标题、卡片标题 |
| 正文字 | `#9FB0C9`（冷灰蓝） | 说明文字、标签 |
> 霓虹色总占比 <15%，靠暗背景衬托发光感，不是堆满亮色。

### 字体
- 标题：无衬线**细体/中体**（科技感几何字体，Geist / Outfit 一类），可带少量英文混排
- 标签：无衬线常规，字号小而清晰，可用等宽字体表现数据感

### 匠人级要求（每次都要带）
成图要像**高端产品发布会主视觉 / 一线大厂技术大会的 keynote 配图**：发光层次细腻、留白克制、对齐严格，绝不是廉价霓虹贴图。

### 反 AI 味护栏（负向，必须避开）
- ✗ 满屏彩虹霓虹、过曝 bloom、糊成一团的光晕
- ✗ 塑料质感3D、廉价玻璃反光
- ✗ 赛博朋克俗套（乱码雨、夸张故障特效）
- ✗ 文字发光过度导致看不清、压边、乱码

## 需要向用户收集的槽位
| 槽位 | 含义 | 必填 | 追问示例 |
|---|---|---|---|
| `{{主标题}}` | 顶部核心主题 | 是 | "这张图的总标题？" |
| `{{副标题}}` | 一句话说明 | 否 | "想配一句副标题吗？" |
| `{{核心结构}}` | 中心要表达的系统/架构/关系 | 是 | "核心要画什么结构？分几块？怎么连？" |
| `{{节点/模块[]}}` | 各模块名称 | 是 | "有哪几个模块/节点？" |
| `{{关键指标[]}}` | 想突出的数字/状态 | 否 | "有要突出的关键数字吗？" |

## 提示词骨架（把槽位替换后整体喂给出图模型）

```
画一张暗色科技风格的技术示意图（dark tech HUD style, premium keynote visual, glassmorphism, subtle neon glow on dark background）。

配色严格使用这套色板，不要自由发挥：主背景深空蓝黑 #0B1220，叠低对比网格底纹 #1E2A44；卡片用半透明玻璃拟态面板 #111A2E + 细边 + 微弱内发光；强调用霓虹青 #34E0E0 与霓虹蓝 #4F8CFF，极少量辅紫 #8B7BFF 点缀；霓虹总占比 <15%，靠暗背景衬托发光。标题字近白 #F5F8FF，正文冷灰蓝 #9FB0C9。
字体：标题用几何感无衬线细/中体（可中英混排），标签用清晰小字、数据可用等宽字体。

【主标题】顶部、近白大字、细体：{{主标题}}
【副标题】标题下方、冷灰蓝小字：{{副标题}}

中心表现【{{核心结构}}】：用玻璃拟态卡片承载各模块 {{节点1}}、{{节点2}}、{{节点3}}……，模块之间用青/蓝发光连接线与流动的数据点连接，体现系统在运转。
活跃节点/关键处用霓虹青高光；如有关键指标 {{关键指标1}}、{{关键指标2}}，用大号发光数字突出。

构图比例 16:9，留白克制、对齐严格、发光层次细腻。成图要像一线大厂技术大会的 keynote 主视觉，绝不能满屏彩虹霓虹、过曝光晕、塑料3D或赛博朋克俗套。所有文字清晰可读、无乱码、不压边。
```

## 已填示例
- 主标题：实时风控决策引擎
- 副标题：毫秒级拦截，亿级吞吐
- 核心结构：请求 → 特征计算 → 规则/模型并行 → 决策汇总 → 输出
- 节点：接入网关、特征服务、规则引擎、模型推理、决策中心
- 关键指标：P99 < 30ms、QPS 1.2M
