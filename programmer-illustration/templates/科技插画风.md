# 科技插画风 模板

> 样图（仅供参考）：见同目录 `科技插画风.png`

## 风格特征（不要改，这是这套风格的灵魂）
> ⚠️ 核心：这**不是**平铺的"图标+圆角卡片网格"。它是**有体积、有纵深、有视觉主角的科技插画主视觉**。平庸的扁平图标网格 = 失败。

- 横向流程，左 → 中 → 右 分阶段推进
- **必须有一个立体的视觉主体（hero）**：通常是中段的处理装置（管道/容器/引擎/机器），有圆柱体积感、柔和高光，像一台精密设备，是全图的视觉中心
- **用物理隐喻容器组织信息**：比如左段用半透明大脑/盒子把输入项"装"进去，而不是把词平铺成格子
- **有纵深**：柔和的渐变背景分区 + 元素的层次投影，让元素"浮起来"，不要全压在一个平面
- 图标**精致、有细节、有插画感、风格统一**，不是通用线性图标
- 右侧用一个友好角色（如 AI 机器人）收尾，有数据流线汇入
- 顶部大号粗体主标题，底部带箭头符号的副标题

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 画布背景 | `#FFFFFF` | 整图底色 |
| 阶段1色块 | `#E8ECEE`（浅灰）/ `#CDE7DC`（浅薄荷） | 起点阶段标题块 |
| 阶段2色块 | `#A8D8C8`（薄荷绿） | 处理阶段标题块 + 中央容器主色 |
| 阶段3色块 | `#9FC8E0`（天蓝） | 终点阶段标题块 + 卡片描边 |
| 主强调 | `#5B9BD5`（青蓝） | 箭头、数据流线 |
| 次强调 | `#E8916B`（暖橙） | 个别需要跳出来的图标/数字 |
| 标题字 | `#2D3A3A`（深墨绿灰） | 主标题、阶段标题 |
| 正文标签 | `#4A5658`（中灰） | 小图标下的文字 |
> 整体冷色调（薄荷+青蓝）为主，暖橙只做极少量点缀，占比 <10%。

### 字体
- 标题：无衬线**粗体**黑体（思源黑体 Bold / Source Han Sans Bold 一类），字重要够重、有力量感
- 标签：无衬线**常规**黑体，清晰易读，字号统一

### 匠人级要求（每次都要带）
成图必须看起来像**专业插画师为科技大会精心绘制的主视觉（key visual）**：有体积、有纵深、有故事感，精致到像打磨了数小时，绝不是随手生成的扁平 PPT 配图。

### 反 AI 味护栏（负向，必须避开）
- ✗ **最致命：平铺的扁平图标网格、没有视觉主角、所有元素压在一个平面** ← 这就是"很平"的根源
- ✗ 糊成一团、风格不统一的通用线性图标
- ✗ 脏兮兮的彩虹渐变、霓虹色、廉价塑料质感3D（要的是柔和体积，不是塑料）
- ✗ 文字挤在一起、压到边缘、错字乱码
- ✗ 那种一眼假的"AI infographic"廉价感

## 需要向用户收集的槽位
| 槽位 | 含义 | 必填 | 追问示例 |
|---|---|---|---|
| `{{主标题}}` | 顶部核心主题 | 是 | "这张图的总标题是什么？" |
| `{{副标题}}` | 底部一句话价值总结 | 是 | "用一句话概括它的价值？" |
| `{{阶段1名称}}` `{{阶段1条目[]}}` | 起点：原始/输入 | 是 | "第一阶段叫什么？里面有哪几项？" |
| `{{阶段2名称}}` `{{阶段2动作[]}}` `{{处理隐喻/hero}}` | 中间：处理/转化（**全图视觉主角**） | 是 | "中间这步在做什么处理？用什么立体装置当主角（管道/容器/引擎/机器）？引出哪几个动作？" |
| `{{阶段3名称}}` `{{阶段3结果[]}}` | 终点：产出/结果 | 是 | "最终产出哪几类结果？" |
| `{{终点角色}}` | 最右收尾角色 | 否(默认 AI Agent 机器人) | "结尾画个什么？默认 AI 机器人" |

## 提示词骨架（把槽位替换后整体喂给出图模型）

```
画一张扁平插画风格的科技信息图（modern flat illustration infographic, professional tech conference key visual）。扁平但**要有体积感、纵深和插画质感——绝不是平铺的图标网格**。

整体氛围：背景用从浅薄荷绿到浅天蓝的柔和横向渐变分区；元素带柔和的层次投影营造纵深，让它们"浮起来"；图标精致、有细节、风格统一、像专业商业插画；画面中央有一个立体的视觉主体(hero)。

配色严格使用这套色板，不要自由发挥：薄荷绿 #A8D8C8、天蓝 #9FC8E0、青蓝 #5B9BD5（箭头/数据流线）、暖橙 #E8916B（极少量点缀 <10%）、深墨绿灰标题 #2D3A3A、中灰标签 #4A5658。整体冷色调。
字体：标题用无衬线粗体黑体（有力量感），标签用无衬线常规黑体，字号统一、清晰易读。

【主标题】顶部居中、大号粗体黑字：{{主标题}}
【副标题】底部居中、前缀箭头符号「›」：{{副标题}}

整体为【左 → 中 → 右】三段式流程，每段顶部一个圆角色块标题：

第一阶段「{{阶段1名称}}」：用一个【{{阶段1隐喻容器，如半透明大脑/盒子/抽屉}}】把下列带精致小图标的输入项"装"进去（隐喻容器，不要平铺成格子）：
{{阶段1条目1}}、{{阶段1条目2}}、{{阶段1条目3}}……

中段「{{阶段2名称}}」是**整张图的视觉主体(hero)**：画一个立体的【{{处理隐喻/hero，如精密管道+容器/引擎/处理装置}}】，有圆柱体积感和柔和高光，像一台数据处理设备；左侧文档/数据流入，装置上标注核心动作，右侧引出多个发光箭头标签：
{{阶段2动作1}}、{{阶段2动作2}}、{{阶段2动作3}}……

第三阶段「{{阶段3名称}}」：一摞竖向的立体卡片，每张卡片有轻微厚度和投影，配精致图标：
{{阶段3结果1}}、{{阶段3结果2}}、{{阶段3结果3}}……

最右侧画一个友好的【{{终点角色}}】，有数据流线汇入它。

构图比例 16:9，有纵深层次、对齐严格、间距均匀、留白充足。成图要像专业插画师为科技大会精心绘制的主视觉，精致、有体积、有故事感；柔和体积与投影即可，不要廉价塑料3D、不要脏渐变、不要霓虹、不要平铺的扁平图标网格。所有中文清晰可读、无错字、不压边、不重叠。
```

## 已填示例（图1原型）
- 主标题：从人脑经验到 AI 可读系统事实层
- 副标题：把隐藏知识变成可检索、可验证、可执行的系统资产
- 阶段1「人脑资产 / 隐性知识」，**隐喻容器=半透明大脑轮廓**，把这些装进去：群聊记录、老员工经验、口头约定、事故复盘、过期文档、临时脚本、代码注释
- 阶段2「结构化治理」，**hero=立体青蓝色精密管道+容器装置（标"抽取"，有体积高光）**，右侧引出：标准化、版本化、关联代码、CI 校验、可检索化
- 阶段3「AI 可读系统事实层」立体卡片：服务事实、领域事实、接口事实、数据事实、运行事实
- 终点角色：AI Agent 机器人
