# 手绘涂鸦风 模板

> 样图（仅供参考）：见同目录 `手绘涂鸦风.png`

## 风格特征（不要改，这是这套风格的灵魂）
- 米黄纸质背景，铅笔 + 彩铅质感
- **火柴人 stick figure** 当主角，讲一个对比/转折故事
- 四周贴**彩色便利贴**（黄/绿/粉/蓝），每张一句金句
- 手写体大标题，**关键词加红色波浪线下划线**
- 关键数字夸张标注（如 40min、100%、11h+）
- 点缀手绘闪光符号 ✦
- 右下角作者签名
- 整体质朴、随性、像翻开的手账本

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 纸张背景 | `#F3EFE3`（米黄，带纸纹） | 整图底色 |
| 主线条 | `#3A3632`（铅笔黑灰，非纯黑） | 火柴人、边框、手写字 |
| 红强调 | `#D8503C`（朱红） | 关键词波浪线下划线、RESET 等冲突元素 |
| 便利贴黄 | `#F7E59B` / 绿 `#CDE6B0` / 粉 `#F4C7C3` / 蓝 `#BFD9E8` | 四角便利贴，交错使用 |
| 关键数字 | `#E08A2E`（暖橙）或朱红 | 突出的数字 |
> 整体暖色调、低饱和、像彩铅本来的颜色，不要鲜艳塑料感。

### 字体
- 大标题/便利贴：**手写体**（马克笔/铅笔手写感，不规则、有人味），绝不能是规整印刷体
- 保持中文手写要自然，笔画可略歪，但必须清晰可读

### 匠人级要求（每次都要带）
成图要像一个**真人花心思手绘的笔记本页**：线条有手感、便利贴有轻微倾斜和阴影、纸张有真实纹理。不能是干净规整的矢量假手绘。

### 反 AI 味护栏（负向，必须避开）
- ✗ 过于规整、对称、矢量化的"假手绘"
- ✗ 鲜艳塑料感配色、霓虹色
- ✗ 火柴人比例怪异、多手多脚、脸部畸形
- ✗ 手写字乱码、便利贴文字糊掉或压边

## 需要向用户收集的槽位
| 槽位 | 含义 | 必填 | 追问示例 |
|---|---|---|---|
| `{{大标题}}` | 左上抓眼球观点 | 是 | "用一句扎心/反差的话当标题？" |
| `{{副标题}}` | 标题下补充说明 | 否 | "副标题想补一句什么？" |
| `{{主角动作1}}` | 左侧起点状态 | 是 | "故事开头，小人在干嘛？" |
| `{{核心比喻}}` `{{关键数字}}` | 中间转折 | 是 | "中间的转折/冲突用什么画面比喻？关键数字是多少？" |
| `{{主角动作2}}` | 右侧对比结局 | 是 | "对比的另一面/结局是什么？" |
| `{{灵魂拷问}}` | 思考气泡里的问句 | 否 | "最后想抛一个什么问题给读者？" |
| `{{便利贴金句[]}}` | 3-6 张便利贴要点 | 是 | "有哪几句金句要点要贴出来？" |
| `{{署名}}` | 右下角签名 | 否 | "右下角签什么名/ID？" |

## 提示词骨架（把槽位替换后整体喂给出图模型）
