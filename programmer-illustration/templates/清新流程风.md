# 清新流程风 模板

> 样图（仅供参考）：见同目录 `清新流程风.png`

## 风格特征（不要改，这是这套风格的灵魂）
> ⚠️ 这套风格的质感来自**清爽的多彩分段 + 泳道编排 + 咬合箭头 + 干净留白**，不追求立体 hero 主体。但它**也不是**廉价扁平：靠色彩分段的节奏、卡片的细描边与轻投影、层级分明的排版撑起精致感。做砸的标志 = 脏乱、色彩打架、卡片不对齐、密到喘不过气。

- **横向多阶段推进**（3–5 段）：每段一个主题色，按 蓝 → 绿 → 橙 → 紫 循环，节奏感来自**色彩分段**而不是体积。
- **阶段头部**：实色圆角长条（同色系深→浅微渐变），左侧是**巨大的独立正圆形白色徽章**（超出条高、浮在前面）,徽章内**超大号 Black 字重白色编号 01/02/03/04**；条内右侧**超粗黑体阶段标题**（Black 或 Heavy 字重）；条下方一行浅色小字说明,头部到第一张卡片留出充足纵向间距（约卡片高 0.8 倍）。
- **阶段之间用 V 形箭头接口咬合连接**,**V 形箭头有立体质感**（同色系浅→深微渐变 + 柔和高光边缘）,不是平面白块。
- **泳道结构**：一个阶段内可分多条横向泳道。每条泳道左侧一个**大圆形彩色主图标**（标准正圆底衬、直径是右侧小图标 2 倍+）+ 泳道名，右侧一串小卡片用箭头串联成步骤链。大小图标尺寸层级明显。
- **支持环形箭头 = 闭环/可循环**：某条步骤链如果是循环的，用一圈回环箭头框成标准正圆闭环,圆环四周留出内边距（约直径 0.15 倍）、不贴列边，闭环中心标注”可多次循环”。
- **卡片**：白底或极浅色底、细描边、小圆角、**明显但柔和的投影**（有浮起来的层次感）；卡片内**顶部居中放标准正圆形彩色图标底衬**（所有图标底衬统一为标准正圆、不是椭圆或扁圆角矩形）,图标下方标题、再下方一行小字,整体竖排居中对齐。卡片之间横向间距约卡片宽 0.3 倍、纵向约 0.4 倍。图标是**同一套精致的实心/微立体插画图标**、风格统一，不混入线性图标。
- **各阶段列等高对齐**：四个阶段列等宽、顶部与底部齐平，内容少的阶段用均匀留白撑齐。
- **底部总结条**：一条浅灰圆角长条，左侧一个圆形徽标，写「核心目标：A → B → C → D」+ 一句副标语。

### 钉死的色板（不要让模型自由发挥配色）
| 角色 | hex | 用在哪 |
|---|---|---|
| 画布背景 | `#FFFFFF` | 整图底色 |
| 阶段1 蓝 | 主 `#2F6BD8` / 浅底 `#EAF1FB` | 第1阶段头部条、图标、卡片描边点缀 |
| 阶段2 绿 | 主 `#4CA678` / 浅底 `#E6F3EC` | 第2阶段 |
| 阶段3 橙 | 主 `#E8963C` / 浅底 `#FBF0E4` | 第3阶段 |
| 阶段4 紫 | 主 `#7A6BD8` / 浅底 `#EEEBFA` | 第4阶段 |
| 卡片底 | `#FFFFFF`（或阶段浅底）+ 描边 `#E6EAF0` | 所有小卡片 |
| 标题字 | `#2B3448`（深蓝墨） | 阶段标题、卡片标题、编号 |
| 标签字 | `#6A7385`（中灰） | 卡片内小字、阶段说明 |
> 多彩但**低饱和、明快清新**。每个阶段只用自己那一段的主题色，**不串色**（蓝段里不要冒出橙色卡片）。阶段头部条用白字，卡片区用深色字。整体大量留白。

### 字体
- 阶段编号：无衬线**超粗 Black/Heavy 字重**，超大号,像巨型徽章数字
- 阶段标题：无衬线**超粗 Black/Heavy 字重**黑体，有强烈力量感
- 卡片标题：无衬线中体，清晰
- 说明小字：无衬线常规，中灰，字号统一

### 匠人级要求（每次都要带）
成图要像**专业 SaaS / 咨询公司做的一页流程图（one-pager playbook）**：多而不乱、色彩清爽有呼吸感、每个卡片对齐到网格、箭头顺滑连贯，一看就是精心排版打磨过的，绝不是随手堆卡片。

### 反 AI 味护栏（负向，必须避开）
- ✗ 色彩打架、饱和度过高、荧光色（要低饱和清新）
- ✗ 阶段之间串色（蓝段里混进别的阶段色）
- ✗ **图标底衬是椭圆/扁圆角矩形/大小不一**（必须是标准正圆、尺寸统一）
- ✗ **投影过浅几乎看不见、卡片贴在底上没有层次感**（要明显柔和投影）
- ✗ **编号徽章小且扁平、字重不够粗**（要巨大正圆徽章 + Black 字重）
- ✗ **V 形箭头是平面纯白块**（要有立体质感:渐变+高光）
- ✗ 卡片横向纵向间距挤、阶段头部到第一张卡片间距不足
- ✗ 通用糊线性图标、实心图标与线性图标混搭、风格不统一
- ✗ 箭头乱指、连线交叉打结、闭环画不圆、闭环贴边压到列边
- ✗ 各阶段列高低参差、某个角落留一大块空白
- ✗ 同一句话（如”可多次循环”）在阶段头部和图内重复出现
- ✗ 中文错字乱码、文字压边/重叠

## 已填示例（中性技术主题）
- 主标题：一次线上请求的四段处理链路
- 阶段1「接入」（流量入口与鉴权），蓝：负载均衡 → 网关鉴权 → 限流
- 阶段2「业务处理」（核心逻辑，分两条泳道），绿：
  - 泳道A 读路径：命中缓存 → 回源查库 → 组装响应
  - 泳道B 写路径：校验参数 → 落库 → 发消息
- 阶段3「数据与缓存」（可循环闭环），橙：写缓存 → 失效 → 回填 → 再命中（回环箭头，标“可多次循环”）
- 阶段4「可观测与承接」（监控与下一步），紫：埋点上报 → 链路追踪 → 告警 → 复盘
- 底部核心目标链：稳定接入 → 正确处理 → 数据一致 → 持续可观测
- 底部副标语：一条清晰、可追踪、可复盘的请求生命周期
