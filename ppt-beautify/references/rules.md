# Hard Rules

These rules are non-negotiable for PPT beautification work.

## Editable Text

- Do not place ordinary text as a bitmap image in the final deck.
- Text from screenshots, posters, profile cards, or mixed image cards must be
  extracted and rebuilt as editable PowerPoint text boxes.
- Titles, subtitles, labels, names, job titles, bios, bullets, numbered lists,
  footers, and callouts must be editable text.

## Image Use

Images are allowed only for real visual assets:

- Real portrait/headshot/half-body photo.
- Official logo, trademark, institution mark, or brand mark.
- Real photo or real screenshot.
- Product or venue image, if relevant and authentic.

Images are not allowed for:

- A full speaker-introduction card that contains text.
- A poster-like block where text is the main information.
- Numbered lists or bullets.
- Decorative text exported as a bitmap.

## Mixed Images

When a draft image combines a portrait and text:

1. Crop or isolate the portrait/headshot/half-body region.
2. Remove or ignore the text region.
3. Recreate the text as editable PPT elements.
4. Visually check that the cropped portrait has no text residue.

## Authenticity

- Never generate fake portraits, fake logos, fake trademarks, fake app icons, or
  fake official marks.
- Use only assets from the supplied draft/reference deck, user-provided assets,
  or verified official sources when browsing is explicitly needed.

## Content Preservation

- Preserve page count unless the user asks to restructure.
- Preserve names, titles, bullet meanings, data, and claims.
- Do not rewrite content for marketing flair unless the user asks.
- If OCR is uncertain, mark the uncertainty and prefer manual visual correction.

## Output Safety

- Never overwrite input files by default.
- Keep the final PPTX editable.
- Render and inspect final slides before delivery.
