# QA Checklist

Run these checks before delivery.

## Structural Checks

- Final slide count matches the draft unless approved otherwise.
- Every slide renders.
- `slides_test.py` reports no overflow.
- No important content is outside the slide canvas.

## Editable Text Checks

- Titles are text boxes.
- Subtitles are text boxes.
- Speaker names are text boxes.
- Speaker titles/roles are text boxes.
- Bios and bullets are text boxes.
- Numbered list items are text boxes.

## Image Checks

- Images are only portraits, logos, trademarks, real screenshots, or real photos.
- No full speaker card image with text remains.
- No text-bearing poster/list screenshot remains.
- Cropped portraits do not include stray text fragments.
- Logos are authentic and sourced from input/reference/official assets.

## Visual Checks

- Font sizes are readable in full-slide preview.
- Body text is not too small for projection.
- Text does not overlap images, cards, badges, or page furniture.
- Long Chinese text does not wrap awkwardly or clip.
- Visual style follows the reference deck's palette and layout language.

## Final Evidence

Keep in scratch:

- Final rendered slide PNGs.
- A final contact sheet.
- Any extracted/cropped visual assets.
- QA command output.
