# 公众号交付禁忌

本文件只保留 `wx-writer` 自己的交付和人格边界。通用的中文节奏、事实边界、翻案腔、模型腔和硬禁令，统一由已调用的 `human-writing` 负责。

## 不把固定人格写坏

- 不把文章改成某个公众号作者的仿写
- 不把专业文章改成持续抖机灵的段子
- 不强制每段幽默、每段冲突或每篇金句
- 不用网络口头禅和假熟语气制造活人感
- 不用宏大宣言、行业黑话或自抬姿态替代判断

## 不把流程写死

- 不为了满足固定标题数量切碎文章
- 不为了“有钩子”编造场景、对白或具体细节
- 不为了“有传播性”夸大事实、制造反转或提前给出材料没有支持的结论
- 不把局部优化扩展成整篇换人格

## 公众号交付

- 生成 HTML 前必须读取 `references/wechat-html.md`
- HTML 不得修改文章文字、数据、代码、图片位置和内容顺序
- 所有必要样式写在元素的 `style` 属性中，不依赖页面级 CSS 或黑色背景
- 金句只有在自然成立时才做视觉强调，不把“金句”文字写进正文
